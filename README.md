# TradeOS

本地优先的个人财富与交易管理系统，包含全局资产、真实交易、策略版本、交易复盘、手动历史回测、绩效分析和财务自由规划。中文界面，默认深色，支持浅色及手机布局。

所有金额以十进制字符串保存、使用 Decimal 计算。真实成交与财富账本共用事务；模拟回测使用独立数据表。无需云账号；股票和ETF可选接入TickFlow更新行情，其他资产价格、汇率与成交仍由用户录入。

## 功能范围

| 模块     | 已实现能力                                                   |
| -------- | ------------------------------------------------------------ |
| 全局资产 | 多平台、多账户、多币种资产与负债，报价、汇率、转账及资产配置 |
| 交易管理 | 策略版本、交易计划、多笔成交、持仓跟踪，统一财富账本         |
| 手动回测 | 历史K线逐根回放、模拟成交、会话分支，与真实交易隔离          |
| 交易复盘 | 复盘记录、附件、规则评分与策略归因                           |
| 绩效分析 | 资产历史、现金流、收益、回撤及交易表现                       |
| 财务自由 | 可投资净资产、目标保存、投入与退休情景模拟                   |
| 数据管理 | CSV导入、对账、完整JSON/SQLite备份及事务恢复                 |

网页版是完整本地应用；安卓目前为独立离线样机，包含现金与现货资产账本、策略版本、风险计划、现货交易日志、复盘与交易绩效、财富与负债、内部划转、财务自由规划、备份和自检。两者的备份格式尚不兼容。

## 开始使用

需要 Node.js 22.12+ 和 npm。依赖包含 SQLite 原生模块；没有适配预编译包时需要本机编译工具。

```sh
git clone https://github.com/SkylarkLiu/TradeOs.git
cd TradeOs
npm ci
npm run db:setup
npm run dev
```

访问 [TradeOS](http://127.0.0.1:3000/wealth)。正式数据库为 `data/tradeos.db`，首次启动是空账本。自定义位置可复制 `.env.example` 为 `.env` 后设置 `DATABASE_URL`；相对路径从项目根目录解析。

首先创建平台和账户，创建资产，录入期初持仓，再更新非现金资产价格及跨币种汇率。建议录入个人财务数据前先阅读 [使用手册](docs/user-guide.md)。

## TickFlow每日行情

在本机`.env`配置`TICKFLOW_API_KEY`，重启服务。进入“资产明细 → 行情数据”，输入证券代码查询并添加资产，再点击“录入持仓”选择账户、填写数量与成本。支持`600000`、`510300.SH`、`00700.HK`、`AAPL.US`等代码。

服务运行时每天北京时间18:00更新已登记股票/ETF的最新行情快照，也可点击“立即更新”。关闭服务不会运行任务，重启会补更；失败间隔30分钟重试，最多3次。沿用报价原始时间，不改持仓、成本或汇率。密钥仅保存在本机环境配置，不进入JSON备份或浏览器。接口权限及网络需由TickFlow账户提供；当前接入不包含安卓原生版或历史回测数据下载。详见[接入说明](docs/tickflow.md)。

## 虚拟演示

```sh
npm run demo
npm run dev:demo -- --port 3002
```

访问 [虚拟演示](http://127.0.0.1:3002/wealth)。演示只写入 `data/demo.db`，包含虚拟平台、交易、历史价格、复盘和回测任务。再次执行 `npm run demo` 会重建演示数据；不能用于保存个人账本。演示脚本检查数据库文件名，禁止写入正式数据库。

## 生产运行与备份

```sh
npm run build
npm run start
```

服务默认只监听本机。设置页提供完整JSON和SQLite备份。JSON恢复先显示记录数量，并自动保存恢复前备份；校验或事务失败保留原数据。不要用CSV代替完整备份，也不要在服务运行时仅复制SQLite主文件。

Docker部署文件已提供：

```sh
docker compose up --build -d
```

Compose绑定 `127.0.0.1:3000`，数据库保存于命名卷 `tradeos-data`。本次仅验证了配置，本机Docker守护进程未运行，尚未完成容器构建和启动验证。不要使用删除卷的命令清理财务数据。

## 安卓离线样机

`apps/android` 使用React、Vite和Capacitor，安卓设备通过原生SQLite保存数据，无需电脑服务器。页面和计算资源打包在应用内；浏览器预览使用sql.js与IndexedDB，属于独立验证环境。

需要Java 21、Android SDK 36及Node.js，设置 `JAVA_HOME` 和 `ANDROID_SDK_ROOT` 后，在项目根目录执行：

```sh
npm ci
npm ci --prefix apps/android
npm run apk --prefix apps/android
```

安装包生成于 `artifacts/android/TradeOS-offline-prototype-0.6.0.apk`，并生成SHA256校验文件。它使用调试签名，仅供当前阶段验收；仓库不提交APK或SDK。

截至2026-10-12，Android 16平板模拟器已验证断网运行、事务回滚、精确金额、进程重启后数据保留和系统文件导出。第一阶段OPPO Pad Mini实机验收已获用户确认通过。0.2.0增加现货资产与报价；0.3.0增加策略版本、风险计划、分批成交、持仓事件与交易占用保护。0.4.0增加单笔/周/月复盘、评分规则快照、标签、按币种筛选的交易绩效和复盘关联的策略改进草稿。0.6.0新增负债余额历史、手动汇率、同币种现金/现货划转与在途资产、资产配置和财富快照，并将FIRE规划接到可投资净资产。缺失或过期报价/汇率只展示已知小计，阻止完整快照和达标预测；房产默认排除，储备账户可配置。0.5.0回测按用户要求暂缓，尚未接入安卓行情数据源。复盘基于手工登记的计划、成交和执行记录；历史K线回测需要真实OHLCV数据，未来可通过本地文件导入或合法数据服务接入。电脑已有的CSV回放功能继续保留。34项安卓业务测试、5项浏览器流程和7项原生测试通过；0.4→0.6覆盖升级保留旧15张表，进程重启后24张业务表一致。新增能力仍待OPPO覆盖安装验收。绩效页统计已平仓交易净损益与该损益曲线回撤金额，尚不计算完整账户TWR/XIRR或净值回撤率。

样机数据库尚未加密，请先使用测试数据；清除数据或卸载应用会删除私有账本与私有备份，应先导出到独立文件。详见[安卓安装与迁移进度](docs/android-migration.md)和[安卓开发说明](apps/android/README.md)。

## 技术栈与目录

网页版采用Next.js、React、TypeScript、Prisma、SQLite、Zod、Decimal.js和ECharts；测试使用Vitest与Playwright。实际安装版本以各自的锁文件为准。

```text
app/                 Web页面及API入口
components/          中文工作台、表单、图表与业务界面
lib/services/        财富、交易、回测、绩效与备份业务
lib/repositories/    Web数据库访问
packages/core/       Web与安卓共用的金额计算和校验
prisma/              数据模型与版本迁移
apps/android/        安卓离线样机及原生文件插件
scripts/             启动、演示、数据库与验收工具
tests/               Web计算、账本与浏览器测试
docs/                架构、使用指南与验收记录
```
