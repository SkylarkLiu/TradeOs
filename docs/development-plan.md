# 开发阶段

- Phase 1：基础工程、全量数据模型、计算基础、导航。
- Phase 2：资产闭环、CSV。
- Phase 3：真实交易闭环。
- Phase 4：复盘、绩效、资产收益。
- Phase 5：隔离手动回测。
- Phase 6：FIRE、对账、备份恢复。
- Phase 7：集成测试、性能、Docker、文档。
  只有对应检查通过后才标记完成。

## Phase 1 完成

数据库迁移、中文导航、主题、精度计算及基础文档。6项单元测试、1条E2E、typecheck、lint通过。提交d3f0f07。

## Phase 2 完成

平台账户、资产、资金流水、含手续费在途转账、多币种估值、负债、完整快照、CSV映射预览/校验/幂等导入/导出。12项测试、2条E2E、typecheck、lint通过。首次浏览器来源校验发现Next内部URL与Host不同，已改为校验Origin与实际Host并验证。

## Phase 3 完成

策略草稿编辑/发布/归档/新版本，交易计划风险仓位计算，无计划交易，分批成交，现货与线性/反向合约，保证金占用，持仓事件与截图。15项测试、3条E2E、typecheck、lint通过。

## Phase 4 完成

单笔/周/月复盘、自定义评分和历史评分规则快照，多维交易筛选、策略版本对比、账户TWR/XIRR、资产价值与收益曲线回撤、现金流/投资损益区分。18项测试、3条E2E、typecheck、lint通过。月度指标明确覆盖实际估值区间；缺少估值边界不输出TWR。

## Phase 5 完成

OHLCV校验、缺口确认和复权声明，服务端按cursor截断数据，逐根前进/回退、播放暂停速度、图表标注、模拟入场/平仓、费用滑点、保守同根规则、回退分支与报告导出。20项测试、4条E2E、typecheck、lint通过。

## Phase 6 完成

FIRE目标、三情景名义/购买力预测、投入缺口、退休后30年支出模拟，对账与账本重建检查，完整JSON（含附件）及SQLite备份，结构/版本/校验和预览，恢复前备份及事务回滚。24项测试、5条E2E、typecheck、lint通过。

## Phase 7 完成

已完成：全量集成、精度和恢复边界加固、历史重建、汇率归因、同时间戳顺序、可投资房地产默认值、现金CSV毛额与收入费用回归修复；手机表格和明细筛选、深浅主题、虚拟演示、部署及使用文档。

主要文件：`lib/services/history.ts`、`summary.ts`、`data.ts`、`analytics.ts`，`proxy.ts`，`tests`，`scripts/demo.ts`，`Dockerfile`、`compose.yaml`及`docs`。

测试结果：34项计算/数据库/访问保护测试、7条浏览器测试（20个主要路由）通过；typecheck、lint、生产构建通过，生产依赖audit为0；正式standalone服务20页和静态资源200，账本空白。界面复核修复3项发现。

遗留边界：Docker配置验证通过，守护进程不可用，尚未完成容器运行；5项开发工具链high依赖告警；尚无大规模压力测试。以上不会标记为已验证，详见testing.md。合约、收益率和FIRE计算模型边界见calculations.md。

正式账本保持空白，演示数据仅在独立demo.db。下一阶段：无未完成的首版开发阶段；进入用户录入、日常使用与按实际规模维护。
