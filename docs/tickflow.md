# TickFlow 行情接入

## 配置和使用

进入“设置与数据管理 → TickFlow设置”，设置自动拉取、每日北京时间、服务节点、API Key以及重试间隔/次数，点击保存即可生效。支持添加和删除时间，保留1–24个时点；保存时去重排序。已有密钥只显示“已配置”，不会回传原文；留空保留，填写新值会替换。连接测试使用当前表单的配置，不会自动保存；立即拉取使用已保存配置，有未保存修改时需先保存。

界面配置保存在数据库文件旁的`<数据库路径>.tickflow.json`，文件权限0600、原子替换，按不同数据库隔离。它不在JSON/SQLite业务备份内，换设备需单独配置。尚未通过界面保存时，沿用`.env`中的`TICKFLOW_API_KEY`、`TICKFLOW_BASE_URL`、`TICKFLOW_DAILY_TIME`和`TICKFLOW_AUTO_SYNC`；环境变量变更需要重启，界面配置优先且无需重启。节点提供默认与香港服务。

在“资产明细 → TickFlow行情”输入代码，查询后确认名称和币种，点击“添加资产”。这一步只登记目录及报价；点击“录入持仓”，选择实际账户，输入真实数量、期初成本与发生时间。账户与资产分开登记，创建账户不会自动获得全市场证券目录。

支持股票和ETF，标准代码为`600000.SH`、`000001.SZ`、`920662.BJ`、`00700.HK`、`AAPL.US`。常见六位A股代码和`NASDAQ:AAPL`等既有代码可转换；无法识别的代码需显式填写市场后缀。现有资产的币种与报价市场不符时不写入价格，保留失败原因。房产、加密资产、场外基金等继续手动维护；现金不需要外部报价。港美股的汇率仍需另行录入。

## 更新方式

- 使用官方`x-api-key`认证，`/v1/instruments`核对名称和类型，`/v1/quotes`查询最新行情快照。当前密钥实测单只接口可用，批量日线返回403；本实现不依赖批量日线权限。
- 默认每天北京时间18:00更新所有已登记、可识别的股票和ETF，可增加多个时点，单只查询相隔至少1秒。任务附着在本机Next.js服务上，浏览器关闭不影响任务，电脑休眠或服务退出时不会更新。重启仅补最近一个到期时点，不集中重跑全部错过时点或补造历史价格。
- 每个时点按北京时间日期分别记录完成状态和尝试次数，保存在SQLite的`SystemSetting`中。默认失败间隔30分钟再试、每个时点最多3次；设置可调整间隔5–180分钟和1–5次；进入下一时点后采用新时点的尝试次数。已完成的时点不会因保存设置而重复执行，旧版单时间配置与已完成任务自动兼容；可随时“立即更新”。权限、认证、限流或服务故障停止本轮后续请求，旧价格保留。恢复正常后可手动重试。
- 并发手动/自动更新合并为同一任务。相同标的和原始时间不重复插入；同一时点已有手动估值时优先保留。来源标记`TICKFLOW`，更新审计不包含密钥。页面刷新后读取最新账本。

## 每日财富快照

电脑版每天北京时间08:00保存CNY完整估值快照，与行情任务独立运行，不需要TickFlow密钥。服务关闭或休眠时不会执行；当天08:00之后启动会保存当前估值，使用实际保存时间，不伪装为08:00，也不补造停机日期。估值缺失或过期时保留旧快照、显示失败原因，每30分钟重试，成功后当天不再自动重存。

手动及自动快照统一按“北京时间日期＋报告币种”覆盖，当天只保留一个快照及对应配置明细，其他日期历史保留。保存时遇到旧版同日多个快照，会在事务内合并为本次新快照。自动任务不修改价格、数量、成本或流水。状态在“设置与数据管理 → 自动估值快照”查看；可通过`SNAPSHOT_AUTO_SAVE=false`暂停，测试账本明确关闭自动任务。

## 财务边界

报价沿用服务返回的原始时间，绝不将旧报价标记成当前时间。假期、停牌或美股尚未开盘时可能返回较早报价，既有估值有效期仍然适用。拒绝零、负数、无效及未来时间的报价；失败不会伪造零价格。行情快照不承诺为当日收盘价。

更新不改变持仓数量、成本、现金、成交、历史估值快照或汇率，也不自动下单、生成持仓或修改真实账本流水。查询证券本身不会登记资产；确认添加后才写入目录。自动任务只更新已登记资产，不拉取整个市场。

这次接入仅用于电脑版及响应式网页。安卓0.6.0继续离线运行，尚未接入该服务；0.5.0历史回测继续搁置，本次未导入日线或分钟K线。JSON/SQLite业务备份保存行情与任务状态，不保存环境密钥；换电脑后需要重新配置。

## 找不到入口或拉取后价格没变化

设置入口为`/settings#tickflow`，查询与添加资产入口为`/wealth/assets#market-data`，两个页面互相提供链接。旧页面没有设置表单，需要刷新后打开新入口；本轮确认浏览器资产页已有行情区，将原来的“行情数据”改为明确的“TickFlow行情”。

拉取成功不等于覆盖手动价格：系统显示时间最新的一条有效估值。如果手动记录时间晚于行情原始时间，页面仍会显示手动来源；同一时点也保留手动记录。现金按单位价值计算，不需TickFlow报价。上次拉取结果可在设置页查看。


## 在持仓中更新

“资产明细 → 持仓明细”和“总览 → 账户资产”提供“更新持仓行情”，仅请求当前已持有股票/ETF；各行“更新”只请求该资产。同一资产跨账户持有时复用同一资产ID和报价，批量请求自动去重。不同资产的并发更新排队，相同范围共享请求，不混用更新结果。现金无需行情更新。

更新后重新读取账本，价格、市值、未实现盈亏随最新有效估值变化，数量和成本保持原样。若保留了时间不早于行情的手动估值，明确提示“手动估值优先”；失败或不支持的资产可展开查看原因。行情通过资产ID关联价格表，无需重复添加已有资产。
