# 金融计算口径与边界

金额使用Decimal 40位有效精度、银行家舍入，数据库TEXT和接口字符串存储。不使用金额Number或SQL浮点SUM；展示格式化不改写账本。计算实现位于 `lib/calculations/decimal.ts` 和业务服务，测试覆盖核心函数及账本联动。

## 估值、资产与成本

有效市值 = 数量 × 截至估值时点最新有效价格 × 报告币汇率。现金在本币价格为1；USDT与USD不自动等价。价格和汇率受设置的最长有效天数约束。缺失或过期时标记不完整，已有可估值部分仍可显示但不能当作完整资产总额。

总资产 = 现货/现金市值 + 在途资产 + 合约未实现盈亏。保证金是现金占用，不额外加资产。净资产 = 总资产 − 负债。可投资净资产只汇总investable资产（含对应在途及合约盈亏）减investable负债，房地产默认排除、可配置。

现货采用移动加权成本。买入后成本 = 旧成本 + 买入数量×价格 + 买入手续费，均价 = 新成本/新数量。卖出移除成本 = 旧均价×卖出数量，净已实现收益 = 数量×卖价 − 移除成本 − 卖出手续费。部分卖出不改变剩余单位成本。

存入非现金资产按输入估值形成成本，外部流量为数量×价格；提现移除平均成本，并记录负外部流量。现金流水数量为毛额输入，余额变化扣除手续费；外部本金按毛额记录，费用作为投资结果的减少。DIVIDEND/INTEREST现金归因取已扣费用的净增量，非现金归因取估值减结算币费用，禁止再次扣费。

内部转账保留原成本，不计全局外部本金。创建时从源端扣除数量和费用，在途数量加入一次全局估值；到账时转移到目标端，不再增加全局资产。普通更正采用追加记录；最近一条独立流水冲销数量、成本、盈亏和现金流，历史原记录保留。

历史快照按流水、成交及当时报价重建，负债按已记录审计历史还原，不能使用当前持仓或后来的负债余额填补历史。缺少负债初始历史时不生成完整快照；资产分类及纳入FIRE配置使用当前设置。净资产峰值取已记录完整快照和当前值，无法代表未记录时点的真实峰值。

## 合约盈亏、均价及仓位

令方向s为多头+1、空头−1，数量q、合约乘数m，入场p₀、出场p₁。

- SPOT/LINEAR毛PnL = s×q×m×(p₁−p₀)。现货不支持无持仓卖空。
- INVERSE毛PnL = s×q×m×(1/p₀−1/p₁)，单位为结算币种。
- 线性加仓均价 = Σ(qᵢ×pᵢ)/Σqᵢ；反向加仓均价 = Σqᵢ / Σ(qᵢ/pᵢ)。
- 参考仓位 = 风险金额 / 单位止损毛损失，风险金额 = 权益×风险百分比/100。
- 风险收益比 = 单位目标毛收益 / 单位止损毛损失；持仓风险敞口按剩余数量与当前止损计算。
- 线性保证金占用 = q×m×入场价/杠杆；反向占用 = q×m/入场价/杠杆。部分退出按比例释放。

手续费以结算币扣除，净成交PnL包含该次费用；入场费用也是负PnL。初始风险固定记录，不随移动止损自动改变。真实成交价格已经包含滑点，slippage字段仅作执行记录，不再次扣减净收益。

止损须为不同正价格，且在入场不利方向；目标在有利方向。风险预算须大于0且不超过100%，乘数和杠杆为正。缺参数或错误方向拒绝计算。参考仓位不预扣未知费用/跳空损失，不能当作交易所保证的最大亏损。

首版不模拟维持保证金、资金费、强平、自动平仓、期权或交易所特殊结算；杠杆只用于记录和保证金占用。

## 交易级绩效与纪律

样本为筛选后的已平仓交易。胜率 = 净盈利笔数/已平仓笔数，保本计入分母。盈亏因子 = 净盈利金额之和/净亏损绝对值之和，无亏损时无有限值。期望 = 净盈亏总额/交易笔数，单位为报告币。

R = 净已实现收益/固定初始风险，平均R忽略无有效初始风险记录。平均持仓小时 = Σ(平仓时间−开仓时间)/笔数/3600000。

跨币种交易金额按平仓时有效历史FX转换；缺失FX提示并排除该交易的可转换金额样本。规则遵守率 = 满足当时全部compliance评分阈值的已复盘交易/已复盘交易，未复盘交易不计入该分母。规则快照来自复盘时配置，盈利和亏损不直接决定纪律得分。

## 账户及组合收益

组合口径使用总资产快照；账户口径使用人工账户估值。现金流进入记正、退出记负；组合只扣EXTERNAL，账户还需要内部转账流。至少两次完整估值及期间有效历史FX。

单区间TWR = (期末价值−期末资金流)/期初价值−1，多区间连乘1+r后减1。实现要求区间内全部现金流落在期末估值时点，估值为资金流后的值；否则缺少现金流边界、拒绝TWR。期初必须大于零。

XIRR求解 Σ[Cᵢ/(1+r)^((tᵢ−t₀)/365天)] = 0。期初/流入投资者现金流取负，流出/期末价值取正。使用Decimal折现、限定域[-0.9999,1000]扫描括区与二分。没有正负流、同日、无有效解或检测多解时提示；有限扫描无法证明全域唯一，使用时须保留求解范围说明。

原始资产回撤 = (过去峰值−当前值)/过去峰值，最大回撤取各记录点最大值。收益曲线回撤基于TWR累乘单位净值；与有外部存取款影响的资产值回撤分别展示。没有有效TWR时不给收益曲线回撤。

月度收益汇总按记录的估值区间归入期末所在月，明确标注不等于完整自然月。首页今日变化 = 当前总资产−上海当日零点快照，包含当日资金流；本月投资PnL = 当前总资产−月初总资产−外部净本金；年初收益采用有边界的TWR。

资产增长归因拆分外部本金、已实现长期收益、Trading成交净PnL、利息分红、汇率变化和调整。汇率变化按FX更新时点之前的持仓及该时点价格分解（价格变化先于FX）；不支持完整衍生品归因时显示未知，不能冒充Trading。剩余变化保留residual，可能包含未实现价格变化、未分解成本或负债等口径差异。

## 手动回测

当前收盘价入场，滑点按bps向不利方向作用；费用 = 结算币名义额×费率，入场和平仓分别计。初始资金和保证金按1倍约束，不使用未来K线。用户设置止损/目标，从下一根开始触发；双触发先止损，跳空止损按更差开盘价，止盈按目标价。手动退出取当前收盘及不利滑点。

回退建立新branch并保留旧成交，报告只统计当前branch。数据需要用户声明复权规则，系统校验而不自动复权、补缺口或模拟流动性。

## FIRE

月增长因子g=(1+年收益率)^(1/12)，月通胀因子h=(1+年通胀)^(1/12)。月末投入，Vₘ=Vₘ₋₁×g+月投入；当前购买力=Vₘ/h^m。

退休剩余月数按365.25/12天向上取整，以填写日期为准。未自定义目标时，退休目标 = 当前月生活费×12×h^m/初始提取率。自定义目标以退休时名义资产解释。

达到目标所需月投入 = max(0,(目标−当前资产×g^m)/A)，A=(g^m−1)/(g−1)；g=1时A=m，m≤0不计算月投入。进度=当前可投资净资产/目标，缺口=max(0,目标−当前可投资净资产)。估值不完整时进度和必要投入返回不可计算。

退休后月末扣除生活费，Vₖ=Vₖ₋₁×g−支出ₖ，支出逐月乘h；模拟360个月，显示首次负资产月份并将图上余额下限显示为0。三个情景为固定假设，不计税、随机路径、医疗冲击或交易所风险，不是收益保证。
