# 金融计算口径
金额使用40位有效精度Decimal、银行家舍入，TEXT存储。禁止金额Number或SQL浮点SUM。

现货成本采用移动加权平均。买入手续费计入成本，卖出手续费扣除已实现收益。入金按期初/流入成本记账；非现金流入须给估值。外部现金流与内部转账区分。

线性合约PnL=方向×数量×乘数×(出场−入场)。反向合约PnL=方向×数量×乘数×(1/入场−1/出场)，以结算币种表示。风险仓位=风险金额/单位止损损失。缺少参数拒绝计算。

R=净已实现收益/固定初始风险；缺失风险显示不可计算。胜率以已平仓交易为样本，保本计入分母。盈亏因子在无亏损时无有限值。平均R忽略无初始风险记录。

TWR仅接受边界现金流，连乘(期末价值−期末流入)/期初价值−1，要求现金流前后的估值边界齐全。缺失边界不得计算。

XIRR使用实际天数/365、Decimal折现、分段扫描及二分求解，域[-0.9999,1000]；无正负现金流、同日、无解或检测多解时提示。有限扫描无法证明全域唯一，结果必须显示求解范围。

回撤=(历史峰值−当前值)/历史峰值。资产值回撤与收益曲线回撤分别展示。资金流贡献不计收益。

FIRE每月末投入，月增长因子=(1+年收益率)^(1/12)，实际购买力=名义资产/(1+通胀率)^(月份/12)。零收益使用线性投入公式。

真实成交价格已经包含滑点，slippage只作执行记录，不重复扣费。合约保证金是现金资产的占用，不增加资产；未实现合约盈亏单独加入账户权益。反向合约加仓采用调和加权均价。首版不模拟交易所的维持保证金、强平或自动平仓，杠杆仅用于记录实际保证金参数。

回测在当前收盘入场，滑点向不利方向施加；止损和止盈从下一根开始。双触发先按止损，跳空止损按不利开盘价，止盈按目标价。费用按结算币种名义额×费率，两侧分别计。回测保证金按1倍，自动撮合仅处理用户设定的模拟止损止盈，不执行真实交易。复权数据须由用户准备，系统保留复权声明，不进行自动复权。
