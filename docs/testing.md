# 测试
Vitest：精度、合约仓位、净盈亏、回撤、TWR、XIRR、FIRE及数据库一致性。Playwright：关键表单到资产/交易/回测的完整路径，单独测试数据库。生产数据不会用于测试。

Phase 1：6项计算测试、1条浏览器测试通过。
Phase 2：12项计算/数据库测试、2条浏览器测试通过；覆盖精度、分批卖出、转账费用、重复导入、余额不足回滚、缺失估值。
Phase 3：15项测试、3条E2E通过；覆盖发布版本不可变、分批成交与账本唯一关联、净手续费盈亏、合约保证金占用。
Phase 4：18项测试、3条E2E通过；账户独立统计、缺少资金流边界拒绝TWR、亏损交易可以获得合规高评分、平仓前禁止单笔复盘。
