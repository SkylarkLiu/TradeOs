# TradeOS 安卓离线迁移

当前安卓版本为0.6.0，已加入财富与负债、内部划转、快照和财务自由规划。0.5.0回测按用户要求暂缓，尚未接入行情数据源。下方保留各阶段交付与验收记录。

## 第一阶段交付（2026-10-10）

第一阶段可行性样机已交付，版本0.1.0，应用名“TradeOS 离线样机”，包名 `com.tradeos.offline.prototype`。安装包位于 `artifacts/android/TradeOS-offline-prototype-0.1.0.apk`，同目录包含SHA256文件。这是调试签名的验收包，尚非完整TradeOS安卓正式版。

样机可离线创建现金账户、登记入金/出金/调整、分别展示各币种余额、计算复利增长、导出JSON、预览并恢复样机备份、运行六项隔离自检。金额以十进制字符串保存，流水与余额在同一事务内写入。操作排队，拒绝余额不足、未来流水与乱序流水。

安卓使用Capacitor原生SQLite，数据库在应用私有目录；不需要电脑服务器，也未声明INTERNET权限。备份通过安卓系统文件选择器读写，不申请全部文件访问权限。恢复前先保存当前账本到应用私有备份目录，并可再次导出。关闭系统云备份和设备迁移备份。此样机数据库尚未加密，请先使用验收数据。

浏览器预览使用sql.js和IndexedDB，仅用于自动化验证，不能作为安卓原生存储的验收依据。网页版仍使用原来的本地服务和SQLite，正式账本未迁移或修改。

## OPPO Pad Mini 安装与验收

1. 将APK复制到平板，用文件管理器打开；按系统提示允许该安装来源。
2. 启动“TradeOS 离线样机”，开启飞行模式，在“离线校验”运行自检，应全部通过。
3. 创建测试账户，入金1000.00000001，登记一笔出金，关闭应用后重新打开，检查金额与流水。
4. 导出JSON到自己选定的文件夹；通过“选择JSON并预览”核对账户和流水数量，再确认恢复。
5. 更新时使用同签名APK覆盖安装；清除应用数据或卸载会删除私有账本及私有备份，请提前导出到独立文件。

## 第三次交付：离线交易版0.3.0（2026-10-12）

安装包 `artifacts/android/TradeOS-offline-prototype-0.3.0.apk`，同包名、同签名、versionCode3。可直接覆盖0.1.0或0.2.0，请先在旧版导出备份，不要卸载。新增功能的OPPO验收仍待用户完成；之前用户确认通过的是第一阶段样机验收。

新增“策略”“交易”工作台。策略规则保存为草稿，核对后发布；同名策略创建递增新版本，已发布版本不能重写。支持归档与恢复策略，归档后禁止新交易引用，已有交易仍可退出。

风险计划记录账户、标的、策略版本、入场/止损/止盈、权益、风险百分比、理由及失效条件。按共用Decimal引擎计算建议数量。现货做多要求止损低于入场、止盈高于入场、风险预算不超过100%。建议数量不代表成交，也不自动发送订单。

交易可关联计划，也可记录计划外交易。关联计划继承其策略版本、初始风险和止损止盈；账户及标的须一致。支持分批建仓、加仓、减仓、全平，实际成交价与费用只入账一次。交易按自己的成交均价统计费用后已实现损益；资产页按账户整体移动平均成本统计，所以多笔交易或既有持仓情况下两者口径可能不同。跨币种损益不直接相加。

成交原子提交AssetLedger、现金余额、AssetHolding、Trade汇总、TradeFill与PositionEvent。普通资产卖出/取出/负调整不能使整体持仓低于各未平仓交易的合计占用，已有现金检查和时间顺序检查仍保留。已平仓交易只读。支持止损/止盈调整、市场观察及计划偏离事件，并拒绝早于开仓、上一事件或成交以及未来时间。

数据库版本3新增Strategy、StrategyVersion、TradingPlan、Trade、TradeFill、PositionEvent六张表，保留0.2.0的全部记录。共用输入及成交变更计算在 `packages/core/src/trading.ts`，Web继续使用原持久化与合约检查；本阶段安卓仅支持无杠杆现货做多。合约、完整回测、复盘评分、附件、负债、转账、汇率和完整版FIRE仍待后续迁移。

备份version3包含策略、计划、交易、成交及事件，可恢复v1/v2。恢复前核对关联、唯一性、时间与顺序，从成交重算交易数量/均价/费用/损益/平仓状态，从事件重算止损止盈，并匹配每笔成交的资产流水，检查历史流水没有动用交易占用持仓。恢复旧备份会替换整个账本，并移除备份中没有的交易与策略；预览记录数后确认，先保存恢复前备份。仍不能导入电脑完整版备份。

## 第四次交付：离线复盘版0.4.0（2026-10-12）

安装包 `artifacts/android/TradeOS-offline-prototype-0.4.0.apk`，versionCode4，沿用原应用ID及签名。先导出旧备份，再覆盖安装；不要卸载旧版。新增能力仍待OPPO实机验收。

### 计划 → 成交 → 复盘 → 改进

1. 在策略页发布策略，在交易页制定风险计划并关联交易。
2. 分批记录实际成交，完成平仓。
3. 在复盘页选择已平仓交易，逐项评分，记录标签、执行差异、经验教训和下一次可检查的动作。也可独立保存周/月复盘，周期复盘不绑定交易。
4. 展开该单笔复盘，参考下一次行动修改策略规则或适用条件，生成同策略新版本草稿。草稿与复盘关联一次事务保存，原版本和原交易不变；一份复盘对应一个改进草稿。
5. 到策略页核对并发布新版本，在后续计划中使用。绩效页可分别筛选新旧版本，继续跟踪执行结果。

评分规则支持调整满分、权重、纪律门槛与纪律项目开关；分数完整、非负、不得超过满分。标准化总分按各项得分/满分乘权重后归一到100。纪律达标要求所有纪律项目达到门槛，与交易是否赚钱分开。保存复盘时保存完整规则快照；后来改规则不会重评历史。每笔交易以最新单笔复盘（复盘时间、sequence）判定纪律，标签保留历次复盘。无纪律项目的样本不计入纪律率分母，界面标明适用样本数。

### 绩效口径

按币种、账户、标的、策略版本、标签和上海时间的平仓日期筛选，只统计已平仓交易完整周期。展示费用后净损益、费用、胜率、盈亏因子、期望损益、平均R、持有时间、复盘覆盖率、纪律达标率和平均评分，并按策略版本及平仓月份归因。初始风险为0不计R；无亏损时盈亏因子没有有限值；跨币种不混算。周/月复盘不计入单笔交易复盘覆盖率。

曲线为已平仓交易累计净损益，从0开始，同一平仓时间合并。回撤为该曲线峰值到后续低点的最大下降金额，不是账户净值回撤率。最长连续亏损按平仓时间及交易ID稳定排序。未平仓浮盈亏、外部现金流、整体账户TWR/XIRR与净值收益率尚未纳入，不能以此替代完整账户投资绩效。

Schema4新增TradeReview、ReviewSettings、ReviewImprovement三张表，旧12张业务表保持不变。备份version4保存全部复盘、规则设置与改进关联，可读v1/v2/v3。恢复时检查复盘评分JSON、规则快照、顺序、已平仓交易、复盘时间、标签与策略版本关联。恢复旧备份会移除其中没有的复盘/改进，并恢复默认评分配置；预览后确认替换，先保存恢复前备份。仍不接受桌面完整版备份。

26项安卓领域测试、4项浏览器流程测试、6项Android 16原生测试通过（飞行模式、无活动默认网络）。实际0.3→0.4覆盖升级，旧12张业务表逐字段一致、Schema4；强制结束并重启进程后15张表一致，评分快照与改进v2草稿保留，原交易仍关联v1。Web48项领域测试、11项浏览器流程测试、类型检查、代码检查、生产构建通过。APK签名及16KB对齐检查通过。

## 第六版交付：离线财富版0.6.0（2026-10-12）

安装包 `artifacts/android/TradeOS-offline-prototype-0.6.0.apk`，versionCode6，应用ID与签名延续。先导出旧版JSON，再覆盖安装；不要卸载。0.5.0未交付，数据库与备份直接由4升至6。第一阶段OPPO验收已通过，本次新增能力仍待实机确认。

### 财富账本与内部划转

- 负债记录名称、币种、余额、时间和是否从可投资资产扣除，保留余额更新历史。登记债务不会自动改变现金；实际借款到账或还款请另记现金流水。
- 现金与现货支持同币种跨账户划转。转出后状态在途，再实际确认到账；在途计入财富一次，到账后改为目标账户资产。禁止跨币种、同账户、超余额/持仓、动用交易占用份额及乱序/未来记录。手续费扣源账户现金，现货成本延续移动平均成本，内部划转不创建交易利润。换汇成交尚不支持。
- 财富按所选报告币种折算，使用手工维护价格和直接/反向汇率，不将USD与USDT等价。没有数据或超过有效期（默认7天）时明示原因与已知小计，不能保存完整快照。
- 总资产、负债、净资产和可投资净资产分别展示，配置含现金、股票、基金、加密资产、债券、黄金、房产、其他和在途。房产默认从FIRE排除；可按资产或账户排除储备资金。负债始终计入总负债，可配置是否从FIRE资产扣除。
- 财富快照记录实际保存时间、报告币种、资产/负债/可投资净额和配置。历史快照固定，不随新价格改变；快照变化不代表投资收益。当前不重建任意历史日期的持仓与估值，也不计算账户TWR/XIRR。

### 财务自由规划

保存目标名称、当前/退休年龄、退休日期、月投入、当前月支出、通胀、保守/基准/乐观收益、年提取率和可选指定目标。同名目标更新，新名称增加目标。年龄与日期须一致，收益假设按情景递增。

以同币种可投资净资产作为起点，计算通胀调整目标、当前购买力目标、进度、缺口、基准所需月投入及三情景退休资产，提供逐年路径。退休后按月支出并随通胀增加，模拟30年并报告首次缺口月份。缺失/过期估值或可投资净资产为负时暂不显示达标结论。模型为固定假设，不包含行情、税费、收益序列风险或随机模拟；FIRE计算在Web/安卓共用，原Web保存与报告接口保留。

### 备份与升级

新增WealthSettings、WealthAccountConfig、WealthAssetConfig、FXRate、Liability、LiabilityBalance、InternalTransfer、FinancialGoal、WealthSnapshot九张表。旧15张业务表不修改字段或记录。备份v6包含所有新表和估值设置，可读v1–v4；不接受未交付的v5。恢复检查负债历史、配置关联、汇率唯一性、划转状态及对应两端流水、目标保存时点与快照恒等式。恢复旧备份会替换整个账本并移除旧备份没有的财富数据，预览后确认，先保存恢复前备份。仍不兼容电脑完整版备份。

OPPO验收建议：覆盖安装后核对旧账；创建两个同币种账户，转出后检查总资产只减少手续费，到账后总额不变；增加负债并更新余额，核对净资产；测试外币缺少汇率，再补汇率；保存快照；排除储备账户，保存财务目标并核对起点变化；飞行模式重开，导出v6、预览并恢复。
