# TradeOS 安卓离线迁移

## 第一阶段交付（2026-10-10）

第一阶段可行性样机已交付，版本0.1.0，应用名“TradeOS 离线样机”，包名 `com.tradeos.offline.prototype`。安装包位于 `artifacts/android/TradeOS-offline-prototype-0.1.0.apk`，同目录包含SHA256文件。这是调试签名的验收包，尚非完整TradeOS安卓正式版。

样机可离线创建现金账户、登记入金/出金/调整、分别展示各币种余额、计算复利增长、导出JSON、预览并恢复样机备份、运行六项隔离自检。金额以十进制字符串保存，流水与余额在同一事务内写入。操作排队，拒绝余额不足、未来流水与乱序流水。

安卓使用Capacitor原生SQLite，数据库在应用私有目录；不需要电脑服务器，也未声明INTERNET权限。备份通过安卓系统文件选择器读写，不申请全部文件访问权限。恢复前先保存当前账本到应用私有备份目录，并可再次导出。关闭系统云备份和设备迁移备份。此样机数据库尚未加密，请先使用验收数据。

浏览器预览使用sql.js和IndexedDB，仅用于自动化验证，不能作为安卓原生存储的验收依据。网页版仍使用原来的本地服务和SQLite，正式账本未迁移或修改。

## OPPO Pad Mini 安装与验收

1. 将APK复制到平板，用文件管理器打开；按系统提示允许该安装来源。
2. 启动“TradeOS 离线样机”，开启飞行模式，在“离线校验”运行自检，应全部通过。
3. 创建测试账户，入金1000.00000001，登记一笔出金，关闭应用后重新打开，检查金额与流水。
4. 导出JSON到自己选定的文件夹；通过“选择JSON并预览”核对账户和流水数量，再确认恢复。
5. 更新时使用同签名APK覆盖安装；清除应用数据或卸载会删除私有账本及私有备份，请提前导出到独立文件。

2026-10-10，用户反馈OPPO Pad Mini实机验收通过，第一阶段设备验收已关闭。验收结论来自用户反馈；本次开发未直接操作该平板。0.2.0新增功能仍需覆盖安装后验收。样机备份与桌面完整版备份格式不同，当前会明确拒绝桌面备份，正式迁移将在后续阶段实现。

## 第二次交付：离线资产版0.2.0

安装包 `artifacts/android/TradeOS-offline-prototype-0.2.0.apk`。沿用原包名与签名，版本号递增，直接覆盖安装0.1.0即可；不要先卸载。开发工具的调试签名仅用于阶段验收，正式发布签名仍在后续阶段。

新增“资产”页，支持股票、基金、加密资产及其他现货的创建、期初持仓、买入、卖出、份额分红、调整、历史报价、持仓成本、已实现损益和估值。缺少报价的持仓明确标记，并将合计显示为已知资产小计。当前按币种分别统计；资产结算币种必须与账户一致，汇率转换与跨账户划转尚未实现。

买入扣除本金与费用，卖出按移动平均成本计算损益，并增加净现金。期初持仓或外部存入不扣本金，手续费照常扣现金。数量、成本、损益、现金和流水同一事务提交；拒绝超卖、现金不足、未来时间和现金/资产混合流水乱序。

本机数据库增加版本标记与Asset、AssetHolding、AssetLedger、AssetPrice表，保留旧FinancialAccount及CashLedger的全部字段、ID和记录。现金和资产流水共用每账户sequence。遇到比当前更新的数据库版本会停止加载并提示升级，不降级或清空数据。

JSON备份升级为version 2，包含资产、持仓、报价和两类流水。仍接受version 1现金样机备份；恢复时按混合流水重算现金、持仓、成本和损益，校验顺序、关联和唯一性。恢复旧现金备份会替换整个当前账本，并移除备份中没有的资产；界面先预览数量、再确认替换、并保存恢复前备份。电脑完整版JSON仍不兼容。

验收建议：先导出0.1.0备份，覆盖安装0.2.0，核对原现金数据；创建一项同币种股票，买入后检查现金扣减与成本；卖出一部分检查数量和损益；更新报价检查估值；开飞行模式重开，再导出和恢复v2备份。

本次验证：11项安卓领域测试、3项浏览器流程测试通过；Web48项领域测试、11项浏览器流程测试、类型检查、代码检查和生产构建通过。模拟器实际由0.1.0覆盖安装0.2.0，逐字段比对旧账户与旧流水完全一致，数据库版本升至2。4项Android 16原生测试通过（飞行模式、无活动默认网络），覆盖现货买入、报价、重开持仓和隔离检查的v1/v2备份恢复；0.2.0新增功能的OPPO验收待用户覆盖安装确认。

独立强制关闭并重启0.2.0进程后，逐表核对现金账户、现金流水、资产、持仓、资产流水和报价共6张表完全一致；模拟器中的测试买入保留数量10、成本101、现金899。


## 第三次交付：离线交易版0.3.0（2026-10-12）

安装包 `artifacts/android/TradeOS-offline-prototype-0.3.0.apk`，同包名、同签名、versionCode3。可直接覆盖0.1.0或0.2.0，请先在旧版导出备份，不要卸载。新增功能的OPPO验收仍待用户完成；之前用户确认通过的是第一阶段样机验收。

新增“策略”“交易”工作台。策略规则保存为草稿，核对后发布；同名策略创建递增新版本，已发布版本不能重写。支持归档与恢复策略，归档后禁止新交易引用，已有交易仍可退出。

风险计划记录账户、标的、策略版本、入场/止损/止盈、权益、风险百分比、理由及失效条件。按共用Decimal引擎计算建议数量。现货做多要求止损低于入场、止盈高于入场、风险预算不超过100%。建议数量不代表成交，也不自动发送订单。

交易可关联计划，也可记录计划外交易。关联计划继承其策略版本、初始风险和止损止盈；账户及标的须一致。支持分批建仓、加仓、减仓、全平，实际成交价与费用只入账一次。交易按自己的成交均价统计费用后已实现损益；资产页按账户整体移动平均成本统计，所以多笔交易或既有持仓情况下两者口径可能不同。跨币种损益不直接相加。

成交原子提交AssetLedger、现金余额、AssetHolding、Trade汇总、TradeFill与PositionEvent。普通资产卖出/取出/负调整不能使整体持仓低于各未平仓交易的合计占用，已有现金检查和时间顺序检查仍保留。已平仓交易只读。支持止损/止盈调整、市场观察及计划偏离事件，并拒绝早于开仓、上一事件或成交以及未来时间。

数据库版本3新增Strategy、StrategyVersion、TradingPlan、Trade、TradeFill、PositionEvent六张表，保留0.2.0的全部记录。共用输入及成交变更计算在 `packages/core/src/trading.ts`，Web继续使用原持久化与合约检查；本阶段安卓仅支持无杠杆现货做多。合约、完整回测、复盘评分、附件、负债、转账、汇率和完整版FIRE仍待后续迁移。

备份version3包含策略、计划、交易、成交及事件，可恢复v1/v2。恢复前核对关联、唯一性、时间与顺序，从成交重算交易数量/均价/费用/损益/平仓状态，从事件重算止损止盈，并匹配每笔成交的资产流水，检查历史流水没有动用交易占用持仓。恢复旧备份会替换整个账本，并移除备份中没有的交易与策略；预览记录数后确认，先保存恢复前备份。仍不能导入电脑完整版备份。

验收建议：覆盖安装后核对旧现金与资产；创建并发布策略，保存风险计划并建立交易；分两笔建仓、部分平仓再全平，核对现金、资产数量和成交损益；记录止损调整；开飞行模式并重开应用；导出v3备份，预览后恢复，核对策略与成交记录。

已完成19项安卓领域测试和4项浏览器流程测试，覆盖金额、故障回滚、多笔交易占用、事件顺序、策略版本、旧备份兼容及不一致备份拒绝。Web48项领域测试、11项浏览器流程测试、类型检查、代码检查和生产构建通过。模拟器实际覆盖安装0.2.0到0.3.0，旧6张表逐字段一致、Schema升至3。原生测试与进程重启验证记录见[测试记录](testing.md)。

本次5项Android 16原生测试通过（飞行模式、无活动默认网络）。强制结束并重启应用后12张业务表逐字段一致，原生交易验收净损益8、持仓0、状态CLOSED、现金1008。APK签名和16KB对齐检查通过；OPPO 0.3.0覆盖安装验收待用户确认。
