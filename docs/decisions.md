# 技术与产品决策

| 决策                            | 原因及边界                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------- |
| Next.js模块化单体 + SQLite      | 按用户指定架构，支持本地独立运行；当前无需微服务或账户权限系统                  |
| Prisma 7.10适配器               | 当前客户端生成器配合better-sqlite3；生成客户端和模型元数据由db:generate统一维护 |
| 金额TEXT + Decimal40位有效精度  | 避免SQLite浮点亲和性；不执行浮点金额SUM；精度上限不是无限精度                   |
| 一个真实账本、独立成交表        | 真实交易和财富余额在同一事务，避免重复记账；回测使用独立实体                    |
| 历史版本发布锁定                | 历史交易保持当时规则；修改建立下一版；评分规则也保存历史快照                    |
| 追加纠错、单调时间和sequence    | 保护历史成本链；相同时间戳有确定顺序；早期记录用调整而非改写                    |
| 缺少估值则显式标记              | 不生成行情，汇率不默认把USDT当USD；不完整数据不用于完整收益指标                 |
| TWR要求现金流边界，XIRR有界求解 | 稀疏手工数据不能伪装精确收益率；月度指标标注实际覆盖范围                        |
| 合约保证金为占用                | 不把杠杆名义额当资产；反向合约用调和均价与结算币风险                            |
| 回测cursor在服务端截断          | 日常回放接口不传未来K线；上一根建立新分支、保留过去决策                         |
| JSON全量恢复 + SQLite一致备份   | 图片、策略、模拟数据都可迁移；恢复先校验、保存旧数据、事务回滚                  |
| 先业务闭环后界面复核            | 中文金融终端方向来自用户brief；深浅主题和移动布局在核心测试之后完善             |
| 单用户loopback                  | 没有登录机制，保护本地访问来源；不用于直接公开互联网部署                        |
| lockfile可复现                  | npm ci按package-lock安装；升级必须重新检查财务测试和本地原生依赖                |

首版不加入自动行情、只读API同步实现、资金费/强平模型、期权模型、税务计算或云端发布。SyncJob是后续只读集成的数据记录接缝；增加集成时保持真实账本唯一来源。

Docker交付为预留部署配置，本次缺少运行中的守护进程，未声称完成容器运行。开发工具链audit告警和个人规模验证范围详见testing.md。
