# 使用手册

## 首次建账

1. 启动正式数据库，进入“平台与账户”。选择Binance、OKX、IBKR、Futu、Alipay、Bank或Other模板，创建平台及其账户。模板仅提供名称。
2. 进入“资产明细”，为资产设置唯一代码、类别、币种和品种。同一个资产跨平台使用同一个资产定义，各账户保存独立持仓。现金代码使用 `CASH:CNY`、`CASH:USD` 等。
3. 进入“资金流水”，用DEPOSIT记录期初现金或现有资产。非现金输入数量和当时估值；存入不会触发买入扣现金。交易类型、数量和费用的填写规则见下表。
4. 在资产页更新报价；跨币种资产填写汇率及时间、来源。没有自动行情。默认7天有效期，可在设置改为1–365天。缺少有效估值时总额会标记不完整。
5. 录入负债，并决定哪些资产及负债计入可投资净资产。REAL_ESTATE默认排除；可以在界面调整。投资目的在持仓中设置。
6. 进入“历史表现”，保存完整估值快照。收益计算依赖历史报价、现金流和快照；今日、本月、年初指标需要对应上海时间零点的快照。可以保存历史快照，系统按当时账本重建。

金额输入使用数字字符串，例如 `0.00000001`，不用千位逗号。日期统一UTC保存，界面显示上海时间；CSV时间必须带时区。

## 资金流水与转账

| 类型                 | 填写方式                          | 含义                                             |
| -------------------- | --------------------------------- | ------------------------------------------------ |
| BUY / SELL           | 正数量、成交价格、手续费          | 买入扣现金、卖出加现金，自动更新成本和已实现收益 |
| DEPOSIT / WITHDRAWAL | 正毛额数量，手续费单填            | 外部本金进入或离开，不作为投资盈利               |
| DIVIDEND / INTEREST  | 正收入数量，手续费单填            | 投资分红、利息                                   |
| FEE                  | 现金资产，数量就是费用，手续费填0 | 单独费用记录                                     |
| ADJUSTMENT           | 正或负数量，非现金需估值          | 纠错或平台差异调整，保留原流水                   |

当前账本要求按账户时间顺序录入，禁止未来真实流水。CSV批次内部按日期排序；已有更晚流水时不能插入更早交易，应通过更正记录处理。最近一条独立普通流水支持撤销，撤销会追加冲销记录。成交、转账及较早流水不能直接删除或改写。

在“内部转账”选择来源、目标、资产、数量和费用。创建后状态为在途，确认实际到账时填写到账时间。全局资产只计算一次在途余额，账户视角显示流出/流入。手续费从源账户扣除，不应另录第二条费用。

总资产和资产明细中的“查看明细”“查看流水”支持下钻；资产链接保留账户和资产筛选。资金流水显示现金变化及成交关联标识。表格可搜索、点击列标题排序、分页；手机横向溢出时显示滑动提示。

## 策略、计划与真实交易

创建策略草稿，在Markdown规则中填入入场、退出、止损、仓位、失效条件、假设及验证结论。发布后该版本锁定；后续变化创建新版本。交易及回测关联当时发布的版本。支持图片附件，图片会进入完整JSON备份。

交易计划输入方向、入场、止损、目标、账户权益和风险百分比。系统按SPOT、LINEAR、INVERSE品种及乘数计算风险仓位。反向合约风险金额以结算币种表示，资产currency必须填结算币种，代码应注明合约。

创建交易并关联计划或策略；没有计划时标记UNPLANNED。随后录入ENTRY/EXIT成交，允许多次加减仓和部分退出。真实成交会写入同一财富账本，不要再在资金流水重复录入BUY/SELL。初始风险为固定值，平仓净收益除以初始风险得到R；手续费只计一次，实际价已包含滑点，滑点字段仅记录执行偏差。

现货首版不支持无持仓卖空；合约支持多空，保证金占用会限制可用现金。合约品种、乘数、结算币种须匹配自己的实际合同。系统不提供交易所强平、维持保证金和资金费模型。

持仓页可记录止损/目标调整、计划偏离和市场观察，历史事件保留。平仓后填写单笔复盘，周/月复盘可单独创建。默认五项评分衡量策略、风险、纪律、心理和完整度；修改评分规则不会改变历史复盘的规则快照。

绩效页面以已平仓交易统计胜率、期望、平均R、持仓时间和策略版本表现。日期筛选基于平仓时间；账户收益使用账户估值，完整组合使用全局快照。资产、策略等交易筛选不改变账户级收益口径。缺少历史汇率的交易会提示数量并从可转换金额指标中排除，不能当作零收益。

## 手动回测

1. 创建任务，选发布策略版本、资产、周期、初始资金、费率及滑点。
2. 上传列为 `at,open,high,low,close,volume` 的CSV，时间带时区；按时间递增，不允许重复。OHLC需正数，成交量非负，高低价包含开收盘。明确复权声明，存在缺口时确认后导入；系统不自动补K线或复权。
3. 使用下一根、上一根、播放、暂停及速度控制。图表和数据接口只显示当前及过去K线。
4. 当前收盘价手动入场，设止损/目标，从下一根开始触发。手动平仓在当前收盘；费用和滑点作用于模拟成交。
5. 同根同时触发按止损优先；跳空止损使用更差开盘价。回退后产生新分支，原分支成交仍保留，报告按当前分支统计并可导出。

模拟数据不会影响真实余额。回测采用1倍资金约束，不模拟实际交易所保证金或流动性。

## 财务自由目标

填写当前/退休年龄、退休日期、月投入、以当前购买力表示的月生活费、通胀、三个收益假设和初始提取率。可直接指定退休时名义目标资产，留空时按通胀后年度生活费除以提取率计算。

当前资产取统一账本的可投资净资产。图表同时显示名义值和当前购买力，计算基准情景所需月投入，并模拟退休后30年的生活费扣除和首次资金缺口。估值不完整时进度和必要投入不可计算。情景采用固定收益率，不包括税费、收入中断或随机收益路径。

## CSV导入、对账和备份

CSV普通流水导入需要先存在对应账户及资产。两个列表提供“导入用ID”；把ID写入CSV并映射accountId、assetId、type、quantity、price、fee、at、note、externalId。预览显示错误、重复及可导入条数，支持下载校验报告；确认后整批提交，任何余额不足等错误都会回滚整批。externalId全局唯一，没有ID时按关键字段生成指纹，相同字段的真实多笔交易应提供不同外部ID。

CSV导出包含全部账本及关联标识。quantity对普通独立流水还原录入毛额，ledgerQuantity是账本净变化；standaloneImport标明是否为独立普通流水。转账、成交、冲销及合约派生流水不能通过普通导入重建业务关系；完整迁移使用JSON。

对账页录入平台实际估值，比较同一时点系统值；“重新推导并检查”核对数量、成本和已实现收益。报告差异不会覆盖历史记录。核实报价、汇率、漏记成交、费用及到账时间后再记录调整。

设置页下载完整JSON（30张表和图片），恢复时先预览表数量，勾选替换确认后提交。系统校验版本、结构指纹、校验和、外键及核心财务关联，恢复前保存 `data/backups` 下的JSON，事务失败保留原数据。同版本当前结构的备份可恢复；跨版本先完成明确的数据迁移。

SQLite备份通过一致性备份接口生成。手工替换数据库前关闭所有服务，保留当前数据库和WAL/SHM文件备份，再替换主文件并清理该旧连接遗留的WAL/SHM后重启。日常优先使用JSON恢复界面。
